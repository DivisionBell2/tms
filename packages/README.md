# packages/

В этой папке лежат **переиспользуемые библиотеки** проекта TMS. Они не запускаются сами по себе, а подключаются как зависимости в `apps/*`.

Состав на разных этапах плана:

| Папка       | Что содержит                                                          | Появится в плане |
| ----------- | --------------------------------------------------------------------- | ---------------- |
| `contracts` | DTO и константы имён сообщений/событий между микросервисами и gateway | Раздел 6 плана   |

> Подпапки появляются **по мере выполнения плана**. На текущем шаге папка `packages/` пустая.

## Правила для пакетов

1. Каждый пакет именуется в namespace `@tms/*` (например `@tms/contracts`).
2. Содержимое пакета должно использоваться **минимум в двух** местах (иначе он не нужен и его создание — нарушение правила «никакого неиспользуемого кода»).
3. Пакет не должен зависеть от какого-либо приложения из `apps/`. Зависимость только в одну сторону: `apps → packages`.
