# apps/

В этой папке лежат **запускаемые приложения** проекта TMS. Каждое приложение — отдельный `package.json`, своя точка входа, свой процесс.

Состав на разных этапах плана:

| Папка                  | Технология | Что делает                                           | Статус  |
| ---------------------- | ---------- | ---------------------------------------------------- | ----------------- |
| `api-gateway`          | NestJS     | HTTP-фасад, проксирует запросы фронта в микросервисы | ✅ |
| `auth-service`         | NestJS     | Пользователи, JWT                                    | ⚙️   |
| `web`                  | SvelteKit  | Веб-приложение для тестировщиков                     | Срез 1            |
| `file-service`         | NestJS     | Загрузка/выдача файлов                               | Срез 2            |
| `test-case-service`    | NestJS     | Тест-кейсы и шаги                                    | Срез 3            |
| `checklist-service`    | NestJS     | Чек-листы                                            | Срез 6            |
| `test-plan-service`    | NestJS     | Тест-планы и история выполнения                      | Срез 7            |
| `gamification-service` | NestJS     | Метрики и ачивки (Event-based)                       | Срез 10           |

> Подпапки появляются **по мере выполнения плана**. На текущем шаге папка `apps/` пустая.
